Finance Manager is a Python-based command-line personal finance management application built using SQLite and SQLAlchemy. It helps users track expenses,
manage categories, set monthly budgets, generate reports, and monitor recurring subscriptions through a simple and interactive CLI interface.
This project demonstrates the practical use of Python, SQLAlchemy ORM, and relational databases in a real-world application.

Features:-
1.Add, delete, and list expenses
2.Automatic category management
3.Search expenses by date range
4.Monthly category-wise spending report
5.Set and track monthly budgets with status indicators
6.Manage subscriptions and view upcoming payments
7.Persistent storage using SQLite

Tech Stack:-
->Language: Python 
->Database: SQLite
->ORM: SQLAlchemy
->Interface: Command Line Interface (CLI)

Overview:-
The application manages expenses, categories, budgets, and subscriptions. Each expense is stored with a title, amount, date, and category.
Budgets are set per month, and subscriptions track upcoming recurring payments. All data is stored persistently in a local SQLite database.
